# تجربة الإطلاق الأولى (First Launch Flow)

## الانطباع الأول للمستخدم (Onboarding)
تعتبر الشاشات الافتتاحية للمستخدم (Onboarding Screens) أساسية في التطبيقات التي تعتمد على مفتاح API خارجي. تم إضافة مسار تعريفي مميز يغطي:
1. **التعريف بالخدمة**: تحويل الصوت إلى نص بدقة.
2. **شرح آلية الرفع**: وكيف يقوم التطبيق بتقسيم الملفات الطويلة وتفريغها في الخلفية.
3. **تكوين الـ API Key**: إرشاد المستخدم لإحضار مفتاح من Groq وإدخاله.
4. **التخطي (Skip) للوضع التجريبي**: لم نرد فرض تسجيل الدخول أو المفتاح من اللحظة الأولى. هناك خيار لتخطي الإعدادات للوضع التجريبي المجاني (Demo Mode).

## بعد التهيئة 
- يتم توجيه المستخدم لـ `HomeScreen`.
- في حال كان بالوضع التجريبي: نعرض "Banner" تنبيهي برتقالي أعلى شاشة التطبيق للتذكير بأن تجربته الحالية محدودة كديمو.
- في حال كان مفتاح الـ API مسجلاً ومشفراً بنجاح، لن تظهر الانقطاعات وسيتمكن المستخدم من التفريغ غير المحدود بسلاسة.
