# دليل الأمان وحماية البيانات (Security Guide)

## 1. حماية المفاتيح (API Keys)
تم إزالة الاعتماد بالكامل على تخزين المفاتيح داخل الكود (No Hardcoded API Keys).  
بناءً على المرحلة **S1**، قمنا بدمج مكتبة `flutter_secure_storage` لتشفير المفاتيح محلياً بدلاً من استخدام `SharedPreferences` الذي يمكن اختراقه.

- **التشفير المحلى:** المفتاح أصبح مشفراً بحزمة `Keystore` للأندرويد و `Keychain` لنظام iOS.
- **التشفير في الذاكرة:** تمت إدارة المفتاح باستخدام Provider بحيث يكون متاحاً في وقت التنفيذ دون كتابته في ملفات Log أو تسريبه.
- **الاستدعاء الآمن:** فقط `GroqApiService` يمرر المفتاح عبر Header آمن في بروتوكول HTTPS.

## 2. الوضع التجريبي (Demo Mode)
تم فصل الوضع التجريبي عن الإنتاج عبر `isDemoMode`.
- **بدون مفتاح:** يمكن للمستخدم اختبار آلية عمل التطبيق، بحيث تظهر له نتائج محاكية ونصوص تجريبية دون الحاجة لاستدعاء الـ API ودون تعريض التطبيق لانهيار (Crash).

## 3. التعامل مع البيانات المؤقتة (Data Retention)
يتم حذف أجزاء الصوت `Chunks` ومسح الذاكرة المؤقتة من خلال مدير الملفات `TempFileManager` بعد اكتمال كل مهمة لتجنب تراكم الملفات واستخراجها بشكل غير قانوني.
